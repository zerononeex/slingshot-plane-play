# Music slots

Drop your own MP3s here (nothing is shipped). Every slot is optional: a missing file means silence.

| File | Plays |
|---|---|
| `menu.mp3` | Home / hangar, upgrades, save codes, results |
| `flight.mp3` | In flight, every world (the default) |
| `space.mp3` | In flight in Space (beats `flight.mp3`) |
| `flight-<world>.mp3` | In flight in that world (beats everything) |

World ids: `plains`, `canyon`, `city`, `snow`, `desert`, `ocean`, `space`, for example `flight-canyon.mp3`.

Tracks loop seamlessly at volume 0.5 and crossfade over about 600 ms. Music starts after the first tap. MUSIC ON/OFF is on Home and in pause.
